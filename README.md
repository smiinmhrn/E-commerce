# Next.js E-commerce

This is a sample e-commerce website built with **Next.js** and **Tailwind CSS**, created primarily to practice and demonstrate core Next.js concepts rather than focusing on a unique or highly polished UI design.

### Next.js Concepts Used

* Image optimization with `next/image`
* Links and navigation with `next/link`
* Static routes
* Dynamic routes and dynamic product pages using slugs
* Route groups
* Pagination
* Not Found pages
* Error handling
* Loading states
* Layouts and multiple layouts
* Reusable components
* Client Components with `use client`
* Props
* React Hooks
* Sliders and interactive components
* Page metadata such as titles and descriptions
* Multiple pages and routes
* Responsive design with Tailwind CSS

The project is responsive across different screen sizes. The main goal was to focus on **Next.js features, routing, component structure, and project organization**, so visual uniqueness, advanced UI design, and modern aesthetics were not the primary focus.
